## Problem statement

Diffusion models and GANs can now produce images that are very hard to tell apart from real photographs. This makes fake images a real risk for social media, news and online scams.

In this project we train and compare several models to classify an image as **Real** or **AI-generated**, and we study how classical models that rely on hand-crafted features compare with deep learning models that learn features on their own.

## Methodology

### 1. Preprocessing
- Convert every image to the **same file format** so the models cannot use PNG/JPEG differences as a shortcut
- Resize to 224 × 224
- Normalize pixel values
- Use the authors' Train / Validation / Test split

### 2. Classical machine learning (hand-crafted features)
Features: colour histogram, HOG and 2D Fourier (FFT) spectrum features

- **K-Nearest Neighbours (K-NN)**
- **Naive Bayes (Gaussian)**
- **Support Vector Machine (SVM)**

### 3. Deep learning
- **CNN with transfer learning** (ResNet50 or MobileNetV2, pre-trained on ImageNet)
- **Hybrid CNN-SVM**: CNN features fed into an SVM classifier

### 4. Hyperparameter optimization
- K-NN: number of neighbours *K*, distance metric
- SVM: *C*, kernel (linear / RBF), *gamma*
- CNN: learning rate, batch size, number of epochs, frozen vs fine-tuned layers

## Evaluation

For every model:
- Accuracy, Precision, Recall, F1-score
- Confusion matrix
- Training and validation accuracy / loss curves (CNN)
- Number of learnable parameters (CNN)

Results are collected in one comparison table in [`results/`](results/).
